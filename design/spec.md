# Mission Control 라벨 디자인 레퍼런스

`README.md`와 `Sources/MissionControlLabels/LabelView.swift`를 확인했다. README의 좌하단·12/11pt 설명은 코드와 다르므로 현재 코드와 요청의 중앙 정렬·15/13pt를 기준으로 삼았다. 앱 코드는 변경하지 않았다.

## 공통 구성

- 이미지: `reference-a.png`, `reference-b.png`, `reference-c.png`, 각각 1536×1024px.
- 설계 좌표계: 960×640pt, 어두운 데스크탑 `#10151E` 기반 그라데이션, 약 640×400pt 창 썸네일 하나, 라벨은 썸네일 정중앙.
- 라벨 문구: `Visual Studio Code` / `LabelView.swift — mission-control-labels`. 라벨에 아이콘 없음.
- 폰트: macOS 시스템 폰트 SF Pro. 앱 이름 15pt semibold(600), 제목 13pt regular(400), 자간 0pt. 설계 행 높이 각각 18pt/16pt.
- 텍스트와 각 배경의 가로 중심을 일치시킨다. 전체 라벨 그룹을 썸네일의 가로·세로 중앙에 배치한다.
- 모든 폭은 패딩·테두리를 포함한 외곽 폭이다. 최대 폭은 `min(400pt, 썸네일 폭 − 32pt)`, 내용에 맞춰 축소한다. 앱 이름 1줄, 제목 최대 2줄, 마지막 줄 말줄임. 목업은 제목 1줄이다.
- 색상은 sRGB이며 아래 알파는 배경 합성 전 값이다. 1px 테두리는 물리 픽셀 기준으로 Retina 2×에서 0.5pt이다.

## 추천: A — 글래스 카드

두 텍스트가 하나의 정보 단위로 읽히고, 28% 검정 틴트는 배경을 약간 비치게 하면서 복잡한 창 내용 위에서도 읽기 쉽다. 현재 LabelView의 폰트·패딩·모서리·틴트를 그대로 활용할 수 있다. B는 두 외곽선이 시선을 더 끌며, C는 가장 가볍지만 밝거나 복잡한 창에서 글자의 대비가 불안정해질 수 있다.

## 생성 방식과 해석

내장 image_gen 도구로 각 PNG를 독립 생성했다. 공통 프롬프트는 어두운 데스크탑, 약 640×400 창 하나, 중앙의 아이콘 없는 두 줄 라벨, 위 문구와 SF Pro를 지정했다. 각 변형에는 위 표의 폰트·알파·패딩·반경·테두리·블러·그림자 값을 추가했다.

PNG는 디자인 방향을 비교하는 생성형 목업이며 픽셀 단위 구현 검증용 스크린샷은 아니다. 각 이미지의 배경 내용·썸네일 위치·폰트 크기·광학적 불투명도에는 생성 오차가 있다. 정확한 구현 기준은 위 표이다. 썸네일의 예시 코드는 실제 저장소 내용을 나타내지 않는다.

Liquid Glass와 NSVisualEffectView의 실제 블러·채도는 시스템 재질이 결정한다. 표의 Gaussian 반경과 채도는 시각 목표이며 해당 AppKit 재질에 그대로 설정할 수 있는 수치를 의미하지 않는다. 현재 BorderView의 `lineWidth = 1`은 AppKit 기준 1pt이므로 물리 1px 목표와는 별도이다.
